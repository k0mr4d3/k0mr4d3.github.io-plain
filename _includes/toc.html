Drop `{% include toc.html %}` into any post where you want the ToC to appear (usually right after the intro paragraph). kramdown fills it in at build time from the post's `##`/`###` headings, so there is no JavaScript and no per-post upkeep -- the output is a plain nested
    of #anchor links that renders on every browser. Jump behavior: browsers that navigate to `id` anchors (modern browsers, and IE around 6) will jump to the heading.
