## Python

```python
# the classic
def main():
    print("Hello World!")  # to stdout
```
Defines a `main` function that prints a greeting to standard output.
{:.caption}

## C

```c
/* the classic, in C */
#include <stdio.h>

int main(void) {
    printf("Hello World!\n");
    return 0;
}
```
The same program in C, returning `0` to signal success.
{:.caption}
